# 安装前提与恢复材料

当前交付开发源码、软件测试和离线检查工具。没有通用刷机脚本，不附带私钥、原厂镜像或设备备份。公开源码不代表某台 Bubble 已通过安装验收。

## 安装前核实

- 本台设备的芯片、Flash、安全状态、PCB、PSRAM 和外设引脚；ESP-VoCat 是候选驱动，外壳名称不能替代 PCB 核实。
- 同一台设备的完整 Flash 备份，按实测容量读取两遍并核对摘要，保留原 NVS、分区、应用、assets 和完整恢复来源。
- 候选应用及分区摘要、软件签名、公钥、槽容量与明确写入范围。不能用其他设备的备份恢复本机。
- 本人对这一次安装或恢复的明确确认。刷写、擦除、安全配置与 USB 配置写入是不同动作。

`profiles/teloa-bubble/partitions.csv` 保留候选布局：NVS `0x9000/0x4000`、otadata `0xd000/0x2000`、PHY `0xf000/0x1000`、应用槽 `0x20000/0x3f0000` 与 `0x410000/0x3f0000`、assets `0x800000/0x800000`，其余 16 MiB 不分配。**只有与本台原布局实际核对后才能使用**；不因容量足够就覆盖原分区、NVS 或资源。

## 工具边界

`tools/teloa.py ports` 只枚举串口；`probe` 会临时进入 ROM 下载模式并重启设备；`backup` 完整读取并复核，不覆盖已有备份；`verify` 在 PCB、外设、安全状态或备份不明时拒绝安装前检查。探测和备份可能中断对话，须由本人选择时间执行。

记录和备份只放在源码目录外的本人私密目录，目录权限 0700、文件 0600。不要上传 GitHub、issue 或模型服务。工具不提供 erase、flash、eFuse 或解锁命令。

`tools/release.py verify` 离线核对 RSA-3072/PSS 清单、应用和分区摘要；应用还须另行通过 ESP-IDF 镜像签名校验。`recovery` 只生成离线报告，始终不会自动安装。恢复原应用、准备双槽试运行记录和恢复完整 Flash 是不同层次；离线材料检查不能冒充已实测恢复。

当前为软件签名校验和回滚，未开启硬件 Secure Boot、Flash 加密或 eFuse，不具备硬件信任根保护；首次写入与整机恢复待实体验证。完整 OTA 下载、宿主升级授权与安装交互尚未交付。
