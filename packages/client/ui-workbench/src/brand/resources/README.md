# 资源识别图标

Simple Icons 图标遵循 CC0，固定来源版本 98820a4dc8c363ca72fa2c0d294ea4a0a9bba75d；Lobe Icons 遵循 MIT，许可证随素材保留。图标用于产品识别，不表示厂商背书。商标权归各厂商。

应用目录与详情共用本地图标。Slack 图形取自 Simple Icons 的固定提交 `0af835e2949a9222965522780e5e0810d3c53382`（CC0），只设置品牌填色。Remotion 与 pstack 图标直接取自本批已审应用的固定原仓版本，分别保留 `remotion-LICENSE` 与 `pstack-LICENSE`（MIT）。Sentry 图标取自目录条目锁定的 `getsentry/plugin-cursor@135513f`（插件清单 `logo` 字段所指 `assets/logo.svg`），保留 `sentry-plugin-cursor-LICENSE`（MIT）。GitHub、Gmail、Google Drive／Sheets／Slides、HubSpot、PostHog、Todoist、Trello 使用 `cursor/plugins@ccb5507cec1546dc88135c1139c811e6c59115ba` 中同名连接插件（`third_party/<名称>`，mcp 服务名与品牌键一致）的原始 logo，保留 `cursor-plugins-LICENSE`（MIT）；只替换已有品牌，不为尚无入口的服务预置图标。文件来源、固定版本、原始／采用摘要和修改见 `app-icons-sources.json`；不从客户端远程加载图标。未提供品牌图标的自建技能使用能力类型图标，不借用同名应用商标。

小松鼠岗位头像为 Teloa 已批准的原创素材，复用既有市场素材；无专属岗位时使用 general.webp。

员工形象内置 28 款岗位与通用小松鼠，选择保存在同一员工身份中。只提供内置形象，不接受自定义图片上传。
