# 技能与连接

Skill 是可复用的工作方法，可以被用户从会话选择，也可以由 Agent 按需要加载。Skill 的正文不等于权限；安装 Skill 不能自动读取团队资料或执行外部操作。

MCP 是连接工具服务的协议。在当前锁定的 DSH 基线中，原生 MCP 客户端桥接工具，不桥接 MCP resources 和 prompts。一个 MCP 服务提供的数据读取能力可以成为数据面的入口，但连接本身不等于知识库。

插件是宿主加载的扩展单元。不同宿主的插件清单和生命周期未必兼容；复用时要逐项检查 Skill、MCP 工具、凭据与界面扩展，不能仅凭插件名称宣称跨平台可安装。

行业资源包组合岗位、业务定义、公共模板、Skill 与连接依赖。市场既应容纳行业内容，也应容纳不依赖行业的公共模板和公共 Skill。导入定义、安装组件、绑定范围和获得授权是不同步骤。

凭据由原生连接或受控授权入口管理，不放进群消息、会话提示词或可分享的资源包。工具出现在目录里只表示已注册；本次调用成功与否应读取实际结果。
