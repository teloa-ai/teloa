# Teloa 实时语音媒体插件

社区版 Web 的持续音频采集、流式 PCM 播放、自然打断与静音。沿用 Teloa 通话入口与当前原会话，识别使用本人所选的本机 SenseVoice 或 MiniMax，所选语音服务负责播报，工作仍由当前角色及任务模型完成。

本包是 DSH `0.2.1-rc.2` 的独立插件，通过 `teloaVoice` 的媒体注册口接入，使用已有语音服务设置和宿主凭据存储。没有单独的模型配置、Agent、长期记忆或业务工具执行面。单纯安装/启动不会录音；首次主动通话才请求麦克风。

MiniMax 使用当前官方 `asr-1.0` 与流式 TTS；这是持续收音和可打断播报的级联链路，模型响应速度仍影响整体延迟。音频仅暂存于有界内存，发送至所选识别/播报提供方，不落录音文件。断线、挂断、禁用和卸载释放媒体，已受理工作继续在原会话执行。

已准备本机 SenseVoice 时，通话复用其固定 Silero 模型判断人声，逐路维护状态，不额外下载。192ms 连续人声确认插话，608ms 尾静音封口，保留首音与192ms尾音；没有模型时使用原音量检测。正式回复按标点分段直接合成 PCM，同一回复保留同一播放代次。插话清空旧播报，取消确认中的新句可走 MiniMax HTTP 流；静音会废弃旧采集与迟到识别结果。

浏览器 PCM 为 16 kHz 单声道输入与 24 kHz 输出；宿主媒体通道使用 `teloa.voice.pcm.v1`，依赖原 DSH 浏览器身份与当前通话票据。最终转写只由实际音频与供应商回执封口，浏览器不能提交文本或模型工具参数冒充本人输入。

## 来源与许可

PCM 连续播放、预缓冲和清播设计改编自 [AlexKaiqi/dsh-realtime-voice](https://github.com/AlexKaiqi/dsh-realtime-voice) `0.3.3` 的 `client/client.js`。其 MIT 版权声明保留在 `LICENSE-MIT.upstream`。Teloa 新增接线遵循仓库 Apache-2.0；上游部分保留原许可。

移植替换了旧版模型运行时和 HTTP/WS 路由，加入原生本人认证、原通话绑定、播放代次、有界队列与可取消资源生命周期。上游原工具执行器和独立语音模型路由不进入本插件。

开发验证：在社区仓安装依赖后执行 `pnpm --filter @teloa/realtime-voice test`。浏览器测试保持无头，使用合成音频和隔离服务，不采集环境音。
