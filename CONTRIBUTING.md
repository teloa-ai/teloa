# Contributing to Teloa Community

欢迎通过 Issue 提交问题或功能建议，通过 Pull Request 提交改动。请描述问题、改动后的行为和验证方式，保持改动范围明确。

源码运行与测试命令见 [README](README.md)。修改接口时请同步契约、客户端与后端测试；DSH 依赖必须保持与 `config/` 中的固定基线一致。

请勿提交凭据、运行数据、个人配置或生成产物。重大安全问题请按 [SECURITY.md](SECURITY.md) 联系 security@teloa.ai。

提交使用 Conventional Commits，并添加 `Signed-off-by`，确认有权按项目许可提供改动；完整声明见 [DCO.md](DCO.md)。

Please use Issues for bugs and proposals, and Pull Requests for code changes. Explain the behavior and validation. Follow the build and test instructions in README, preserve the pinned DSH dependency baseline, and never include credentials or runtime data. Add a DCO sign-off to commits. Report critical vulnerabilities through the private channels described in SECURITY.md.
