# 自动化与市场工具栏响应式复核

分支：`codex/bugfix-ui-optimizations`。对照提交：`fb88d6c`。

根据两张截图修复自动化错位与应用工具栏分行，并继续排查同类的控件高度、窄容器、长内容和键盘交互问题。保留现有暖灰、墨黑品牌及主题、字体设置。

## 发现与修复

| 级别 | 问题与证据 | 修复 |
| --- | --- | --- |
| 高 | 自动化标题、页签、搜索采用不同的宽度和边距。修改前在 2560 宽视口中，三者左边线分别为 640、40、640，页签偏移 600 像素。 | 清理相互覆盖的旧页头、绝对定位与页签规则；标题、页签、计划目录、执行记录共用版心和按容器宽度计算的边距。 |
| 高 | 应用搜索与“我的应用”是两个独立块，即使宽屏仍固定占两行。 | 搜索、我的应用、可用的模板入口、添加菜单组成一条工具栏。空间充足时同排；窄屏或大字号时按组回流。DOM 顺序与键盘顺序一致。 |
| 严重 | 390 宽、28 字号下，市场分类按钮收缩到小于文本宽度，文字相互挤压。 | 分类按钮保留内容宽度，导航自然换行；消除依赖浏览器宽度的隐式挤压。 |
| 高 | 宽浏览器中的窄应用目录仍按视口决定双列，放大字号后内容和操作争抢宽度。 | 应用目录使用命名容器查询，根据目录实际宽度与字号切换单双列。自动化卡片同样按容器回流，状态可以放到标题下方。 |
| 中 | 复合搜索既有外壳留白，又继承通用输入框的 9px 内边距。浏览器测得 14 字号的应用搜索外壳高 60px，其中输入框已高 42px。 | 对明确标记的复合输入统一取消内部边框与留白；外壳负责尺寸、边框与焦点。保留独立表单输入的样式。 |
| 高 | 添加菜单刚展开后快速按 Escape，原生 details 已打开而 React 的关闭监听可能尚未建立；原回归稳定超时。 | 应用添加与页头创建入口通过受控点击更新展开状态，保留原生 Enter/Space 触发。验证快速 Escape、从菜单选项关闭、回到触发器和无业务写入。 |
| 中 | 大字号长执行标题容易把状态、打开任务操作挤在一起；菜单亦需考虑窄容器。 | 执行标题预留可阅读宽度，状态与操作自然回流；菜单尺寸受容器约束，验证应用添加与页头创建菜单都在边界内。 |

## 浏览器验收

新增 `responsive-page-toolbar.browser.test.ts`，复用既有真实 `ContinuousPage`、`MarketPage` 及 API 夹具，构建实际 CSS，未另画页面替代实现。

- 视口宽度：320、390、768、1024、1440、2560。
- 额外容器：2560 宽浏览器中的 420、720 宽面板。
- 字号：14、28；浅色与深色主题。共 32 组尺寸、字号和主题组合，分别检查计划、执行记录、市场应用，共 96 个主要布局状态。
- 数据：1000 条计划、首批 50 条、全量检索第 999 条；60 条长执行记录；120 个应用并检索末项；另检查空计划目录和单条目录的创建入口。
- 几何检查：页头、页签、搜索左边线；宽屏搜索与我的应用同排；页面与窄容器无横向溢出；分类按钮不小于其文本宽度；复合搜索高度；两类菜单边界。
- 交互检查：搜索后 Tab 到我的应用；Enter 打开菜单；快速 Escape 关闭；从选项关闭回焦；搜索与视图切换保留查询；打开抽屉和菜单不会创建、执行或添加内容。

同时用可见 Chrome 检查了桌面自动化、桌面应用工具栏、390 宽双倍字号自动化与市场、窄屏创建菜单。预览使用隔离数据，服务于界面验收。

通过 `TELOA_UI_TOOLBAR_PREVIEW_DIR` 可以输出静态验收预览；`TELOA_UI_SCREENSHOT_DIR` 可以保存截图。本次证据位于 `.runtime/responsive-toolbar-evidence/`；预览和运行数据不进入提交。

## Apple Design 原则的网页适用范围

- `layout.md › Adaptability`：“Design a layout that adapts gracefully and consistently.” 本次转为 CSS 容器宽度、字号回流和共享边线验证。
- `toolbars.md › Item groupings`：“Group toolbar items logically by function and frequency of use.” 搜索与其目录操作组成一组，保留清晰间距。
- `accessibility.md › Speech`：“Let people use the keyboard alone to navigate and interact with your app.” 通过实际键盘操作验证搜索、菜单和回焦。

采用信息层级、可缩放文字、逻辑分组与键盘可达等跨平台原则。尺寸以网页 CSS 像素及相对单位实现；未引入 Apple 原生平台的 pt 尺寸、系统材质或系统导航规范。
