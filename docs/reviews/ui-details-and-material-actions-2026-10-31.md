# 任务详情、下拉框与资料操作复核

分支：`codex/bugfix-ui-optimizations`。对照提交：`967f198`。

针对本轮七张截图修复实际布局和组件状态，继续保留暖灰、墨黑品牌及现有字体、主题设置。

## 问题与处理

| 问题 | 原因与修复 |
| --- | --- |
| 滚动后正文露在任务标题上方、两侧 | 标题位于有内边距的滚动面中，原 `top:0` 及背景只覆盖内部内容宽度。让标题背景延伸至滚动面边缘，并以各布局实际的纵向、横向内边距定位。分别覆盖普通详情、列表中的详情卡片和嵌入视图，不再假设所有视图内边距相同。 |
| 完整阅读模式的长正文不能在详情内继续滚动 | 原完整阅读模式把详情改为 `overflow:visible`，外层却限制高度。完整阅读模式继续使用同一个详情实例及滚动面，保留表单、焦点和任务身份。 |
| 原生下拉框箭头贴边、文字空间不足 | 统一单选框的箭头位置及右侧留白，保留原生选择、选项和键盘输入定位。多选框及列表不改；系统高对比度模式恢复原生箭头。 |
| 市场页头入口被拉散 | 页头操作组与创建菜单各自占用了弹性空白。改为完整的一组靠右排列，窄宽度与大字号按组回流。 |
| 市场卡片悬浮时底部出现白条 | 无替代版本时，补充组件返回空内容，但父卡片仍渲染带留白的补充容器。隐藏空补充区，保留底部圆角；存在实际补充内容时，上下区域使用一致的悬浮背景。 |
| 知识正文前出现内部来源字符串 | 原始来源字段被直接当作正文说明渲染。将完整来源保留在文档后的默认折叠“来源、版本与使用范围”中，阅读正文不再先看到 `resource:…`、`market:…`。资源身份、固定版本和引用不变。 |
| 员工文件树混入批量业务按钮 | 左侧目录保留文件、分组和成果。批量采用、全部加入检索移至右侧“员工资料操作”菜单，先显示员工及资料数量，支持选择员工；沿用原操作流程及权限。用于其他业务仍打开抽屉。 |
| 共用筛选弹层在窄屏撑开内容 | `DirectoryFilterPopover` 漏挂了既有的 `filterPanel` 样式。补回背景、边框、滚动高度及移动端定位；为需要明确名称的资料菜单提供文字入口，并保留标题提示及键盘回焦。 |

## 验收

使用实际 `TaskDetail`、`TaskList`、`ResourceManager`、`ContinuousPage`、`MarketPage` 及现有 API 夹具构建页面，未在测试中重画产品组件。

- 任务：普通、卡片、嵌入、完整阅读四种布局；1400/720 宽，14/28 字号；实际滚动后检查顶部及两侧边界、顶部命中元素和不透明背景。补验长正文确实能在详情滚动面中阅读，并保留原任务菜单、状态及返回契约。
- 资料：390/768/1440 宽，14/28 字号；菜单保持屏内、不横向溢出、不撑高工具栏，抽屉不挤占资料上方空间。沿用 16 项资料采用测试，覆盖未知结果恢复、部分失败继续、新旧业务范围隔离；员工检索保留来源去重验证。
- 来源：实际采用后的文档默认不显示内部来源，展开来源详情后可以读取完整原值；展开本身不修改资料。
- 市场与自动化：320/390/768/1024/1440/2560 宽，另含宽浏览器中的 420/720 窄容器；14/28 字号、深浅主题。验证页头分组、空卡片补充区、底部圆角、悬浮前后尺寸、搜索与菜单回焦。
- 大目录：1000 条计划、60 条长执行记录、120 个应用；另含空计划目录及单条目录。验证检索末项、分类文字及页面边界。
- 原生下拉框：检查文字与箭头留白、实际键盘输入定位选项，以及系统高对比度下的原生外观。
- 可见 Chrome：观察任务长正文滚动、桌面和窄屏详情、市场页头大字号布局，以及桌面和 390 宽大字号资料操作浮层。

相关回归 17 份文件、107 项全部通过，0 失败、0 跳过。工作台包构建、客户端类型检查、客户端构建边界检查及 DSH 依赖检查均通过；本次未运行全量测试。

浏览器使用隔离夹具；未写入用户数据库、未重启 3100 服务。测试可通过 `TELOA_UI_TOOLBAR_PREVIEW_DIR` 导出预览，通过 `TELOA_UI_SCREENSHOT_DIR` 保存截图。本轮本地证据位于 `.runtime/ui-details-evidence/`，不提交运行数据和生成产物。

## 网页与原生平台边界

本轮继续应用 apple-design 的信息分组、可阅读层级、可缩放文字、低频信息渐进披露、滚动边界及键盘可达原则。网页实现使用 CSS 像素、相对单位、容器查询、原生 HTML 表单及浏览器高对比度模式；不套用 Apple 平台专用的 pt 尺寸、系统材质、导航栏或原生菜单规范。
