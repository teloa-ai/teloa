# 检索批量管理、语义试搜与项目创建表单

分支：`codex/bugfix-ui-optimizations`。改动前对照：`49b75b1`。

本轮包含新建项目弹窗和资料检索两组用户反馈，保留现有品牌、主题和本人字号设置。

## 修复与交互

| 问题 | 改动 |
| --- | --- |
| 项目描述输入框变成窄栏，标签落在输入框底部 | 校验容器改变了标签的层级，原样式只匹配表单直接子标签。统一匹配表单内标签，描述、名称和业务选择纵向排版并占满字段宽度。项目表单独立滚动正文，标题和提交操作保持可见；保留必填反馈、草稿和完成确认契约。 |
| 检索只能逐项移出，不能选择任意资料批量加入 | 在本地检索提供“管理检索资料”抽屉。可搜索全部可用资料、逐项选择、全选当前筛选结果、清空选择；首批显示 50 个来源，逐批展开。按来源去重并说明同源影响，跨筛选保留选择并提示隐藏选择数量，分别显示可加入和可移出的数量。 |
| 批量操作的范围与失败不明确 | 沿用已有 `sourceIds` API、本人权限和 500 来源上限。后端批次原子校验，失败时保留整个选择用于重试；成功后只清除本次已处理项。索引后台进行，各资料的整理/失败状态继续显示。移出只删除检索登记及索引，原资料保留；进行中阻止重复提交与关闭。 |
| 实际试搜时查询框消失、查询中断 | 原组件只在模型 ready/standby 时挂载。冷查询触发 loading，状态轮询把试搜组件卸载并中止请求。保留组件与查询，模型阶段变化不取消查询；模型身份、资料版本或可见页面改变时丢弃过期请求及结果。增加单次试搜取消，不调用停止后台索引接口。 |
| 命中片段反馈与长内容阅读不足 | 显示已检索/未就绪数量及未就绪资料原因。保留命中原文、版本、行范围和标题；长片段换行、限高且可键盘滚动。只播报简短状态，避免把全部片段作为 live region 反复朗读。 |
| 模型下拉框出现两个箭头 | 自带装饰箭头的选择器退出全局箭头装饰，保留原生选项、键盘和完整型号提示。系统高对比度隐藏装饰 SVG、恢复原生箭头；普通业务筛选继续使用统一箭头。 |

## 验收范围

- 项目：24 个创建/编辑、320/390/768/1440 宽度、14/28 字号、深浅主题组合。检查标签位置、字段宽度、错误聚焦、长描述原样保存、正文滚动后标题及操作位置，以及不重复保存。
- 检索：实际产品组件覆盖模型冷启动轮询、取消回焦、模型身份改变后的迟到结果、命中原文与行范围、未就绪原因，以及长片段键盘滚动。
- 批量：600 个来源、同源多份资料、只挂载首批及展开、搜索第 600 项、跨筛选选择、整批失败重试、双击去重、忙碌时关闭保护、超限禁用、移出后原资料仍可选择。
- 响应式：320/390/768/1440 宽度 × 14/28 字号 × 深浅主题，共 16 个检索界面组合，检查正文及抽屉横向边界、固定标题和批量操作位置；补验系统高对比度和普通筛选框键盘行为。
- 后端：独立 PostgreSQL 容器验证批次中存在无效来源时全部回滚、重复加入幂等、多来源同时移出只清索引、未选来源仍可检索、全部原资料保持 active。

相关测试共 182 项通过，0 失败、0 跳过：项目 94 项、既有检索/本地模型/响应式工具栏 69 项、新增浏览器场景 4 项、真实 PostgreSQL 检索 15 项。工作台构建、客户端与后端类型检查、客户端构建边界及 DSH 依赖核对均通过；未运行全仓测试。

测试使用真实组件和隔离夹具，截图及运行日志位于忽略目录 `.runtime/project-retrieval-evidence/`。不提交数据库、凭据、程序快照或生成产物。实际 3100 浏览器验收另保存在本机私有运行记录中。

适用 apple-design 的网页原则为层级、渐进披露、清楚的表单反馈、可缩放文字和键盘可达性。实现使用 HTML 原生表单、dialog、CSS 相对单位和浏览器高对比度；不套用原生 Apple 平台的材质、pt 尺寸或导航规范。
